# AstraNightly

One-file web experiments. No dependencies, no build step, no framework —
a page opens, and the whole thing is already there.

Three so far:

- [**qvorr**](https://astranightly.github.io/qvorr/) — a mandelbulb raymarched live in WebGL2
- [**vlarn**](https://astranightly.github.io/vlarn/) — a subtractive synthesizer in the Web Audio API
- [**zvorn**](https://astranightly.github.io/zvorn/) — a chess engine with an alpha-beta search

Each is a single `index.html`. Each does a different kind of work: light,
sound, thought.

Occasionally something else shows up here.
